# カレンダー起点のサポートページ作成要件

## 目的

支援の具体的な内容を決める前に、主催者がページを作って保存できるようにする。カレンダーの日付と標準カテゴリを選ぶだけで最初の予定を登録し、詳しい内容は後から整えられるようにする。

## 変更要件

- 必須入力はサポートする方の呼び名。期間は2・4・8週間の選択肢を初期値付きで提示し、開始日は初期値を使える。
- 作成直後は予定0件の非公開下書きとする。公開ページや共有URLとして閲覧できない。
- 管理画面のカレンダーから単日または複数日を選び、標準カテゴリと初期設定の予定名を使って予定を追加できる。
- 時刻、公開説明、受け渡し概要、非公開指示、食事の注意は任意とし、後から編集できる。非公開情報は既存の別コレクション・公開投影の境界を保つ。
- 予定0件では画面とサービス層の両方で公開を拒否する。公開中の予定追加は保存と同時に募集へ反映する。
- 所有者、ページ状態、期間、過去日、60件上限、revisionをサーバーで検証し、ページ一覧の更新と予定・秘密情報を一つのFirestoreトランザクションで確定する。
- 公開中ページに少なくとも1件の予定を残す。既存の担当済み予定変更禁止、匿名担当、キャンセル、通知、個人情報保護を維持する。

## 受け入れ条件

1. 必須入力だけで予定0件の下書きが作成され、公開側には表示されない。
2. 日付を選びカテゴリをタップして予定を追加でき、複数日の一括追加もできる。
3. 時刻・詳しい説明を入力せずに予定を保存できる。非公開指示と食事注意は公開レスポンスに含まれない。
4. 予定がない下書きは公開できない。公開中ページの新規予定は共有ページに表示される。
5. 他者、期限外・過去日、古いrevision、61件目の追加が拒否される。
6. 375/390/430pxで作成から公開・匿名担当まで操作できる。
